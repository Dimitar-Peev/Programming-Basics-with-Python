# Programming Basics with Python
Contains solutions from the SoftUni course.

<h3>For the course</h3>
<p>The “Programming Basics” course provides the foundational programming skills required for all technology majors at SoftUni. 
This includes writing basic code (basic coding skills), working with an integrated development environment (IDE), 
using variables and data, operators and expressions, working with the console (reading input and printing results), 
using conditional statements (if and if-else), and loops (for and while).</p>
